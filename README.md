# CHATBOT (B4A)

An Android chatbot app built with **B4A (Basic4Android)**.

## Requirements
- [B4A (Basic4Android)](https://www.b4x.com/b4a.html) IDE
- Android SDK

## Installation
1. Clone the repository
   ```
   git clone https://github.com/codexvisual/CHATBOTApp.git
   ```
2. Open `chat.b4a` in B4A
3. Connect a device (or use the B4A bridge) and click **Run (F5)**

## Notes
- Requires the B4A libraries referenced in the project (see `.b4a` manifest section).
